## Key decisions
1. **Aesthetic = brutalist concrete** (chosen by user over editorial/Swiss, blueprint, industrial).
2. **Audience = private real-estate developers** (drives "evidence next to claim", real numbers not adjectives).
3. **Theme = light default + dark toggle** persisted to localStorage. Dark mode redefines the semantic token layer only (per `color-and-contrast.md`).
4. **Palette derived from logo**: #030351 = 94.5% of logo pixels → `oklch(20% 0.13 275)`. Concrete neutrals with warm cast (chroma 0.004–0.008, hue 75). Single accent: safety orange `oklch(63% 0.19 48)`. Never pure black/white.
5. **Font pairing**: Vazirmatn 900 for display (heavy, structural), Vazirmatn 400/700 for body, JetBrains Mono 700 for technical labels. No Inter/Roboto.
6. **Cards banned except project grid** (the one place side-by-side compare warrants them). Services/credentials/timeline use numbered rows with hairline rules + hover invert.
7. **Stats as datasheet spec block, not hero metrics template** (the `impeccable` skill explicitly warns against "3 stats in a centred row under a subhead").
8. **9 projects** with **8 distinct SVG drawing types** — each is a real architectural-drawing motif (tower elevation, plan, section, bridge, dome, etc.), with crop marks, dimension lines, mono labels, project code. No AI gradient placeholders.
9. **Team photos**: grayscale by default, colour on hover (`filter: grayscale(1) → grayscale(0)` on hover). Optimised to 600px wide, WebP + JPG fallback.
10. **Team names are placeholder** ("نام — معاون فنی" etc.) — user to replace in `js/team.js` with real names. CEO name is real (محمد منزوی from the bio).

## v3 — brutalist rejected, rebuilt as "refined institutional"

User rejected the brutalist v2 outright: *"it is a company site"*. All four failure
modes confirmed: too harsh/raw, too technical/cold, too loud/attention-seeking,
colours/texture wrong.

**Lesson recorded:** the `impeccable` skill says "pick an extreme, not a middle
ground." That rule is for products that need to be *memorable*. It is wrong for
corporate/consulting sites where the buying signal is *credibility and low risk*.
I marked brutalist "(Recommended)" and it was the wrong call. For B2B professional
services, restraint beats personality.

**v3 direction — refined institutional (Arup / WSP register):**
- Palette: warm stone neutrals (hue 85) + logo navy `#030351` + restrained brass
  accent `oklch(54% 0.11 68)`. Safety orange dropped.
- Radius: 3 / 6 / 10 / 14 / 20px. Zero-radius banned.
- Soft layered shadows (xs→xl), never heavy.
- Type: Vazirmatn 400/500/600/700 only. Monospace removed from the UI entirely.
  Hero tops out at 3.5rem (was 9.5rem).
- Removed: marquee ticker, section numbering, dimension lines, crop marks,
  concrete grain texture, inverted harsh blocks, giant display type.
- Added: soft cards with gentle hover lift, eyebrow labels with small rules,
  centred symmetric layouts, generous whitespace.
- Project art rewritten: warm minimal architectural *line illustrations*
  (thin navy strokes on subtle surface, faint skyline, ground line) replacing the
  cold technical drawings. 8 types, all validated — 9/9 render, zero leftover
  v2 technical annotation.
- Team photos now full colour with soft shadows (was grayscale `filter`).
