نسخه Next.js

وب‌سایت الان با Next.js توسعه داده می‌شود و بعد از بیلد، خروجی کاملاً استاتیک در پوشه naji-sazan-amin-next/out ساخته می‌شود؛ همین خروجی روی هاست واقعی هم آپلود می‌شود، پس چیزی که لوکال می‌بینی دقیقاً نسخه نهایی است.

پیش‌نیازها: برای بیلد، Node.js لازم است. برای روش اجرای اول، Docker Desktop هم باید نصب و روشن باشد.

اولین بار یک بار بیلد بگیر (روی سیستم من همین الان انجام شده)، بعدش با هر کدوم از روش‌های زیر سایت رو بالا بیاور:

روش‌های اجرای وب‌سایت روی سیستم شما
۱ روش اول: اجرا با داکر (پیشنهاد اصلی من — دقیقاً مثل سرور واقعی)
لینک ثابت: localhost:8080

یک کانتینر nginx با همان تنظیمات، هدرهای امنیتی و قوانین کش سرور اصلی سایت را سرو می‌کند:

  1. اولین بار (فقط یک بار) بیلد را بساز:
    cd naji-sazan-amin-next && npm ci && npm run build
  2. سرور را روشن کن و در مرورگر http://localhost:8080 را باز کن:
    cd naji-sazan-amin-next\deploy\local && docker compose up -d
  3. برای به‌روزرسانی سایت بعد از تغییرات، فقط npm run build بزن؛ نیازی به ری‌استارت کانتینر نیست.
  4. برای خاموش کردن: docker compose down
۲ روش دوم: اجرای بدون داکر (با پایتون)

در پوشه اصلی پروژه روی فایل Run.bat (یا اجرا.bat) دابل‌کلیک کن؛ پورت خالی (معمولاً ۸۰۰۰) خودکار پیدا می‌شود، سرور روشن می‌شود و مرورگر هم خودش باز می‌شود.

از ترمینال هم می‌شود:

python serve.py

این روش همان پوشه out را سرو می‌کند؛ فقط پشت‌صحنه‌اش سرویس وب ساده پایتون است، بدون هدرهای امنیتی nginx.

۳ روش سوم: حالت توسعه (برای تغییر دادن سایت)

اگر خواستی کد سایت را عوض کنی، به‌جای خروجی استاتیک، سرور توسعه Next.js را اجرا کن تا تغییرات همان لحظه دیده شوند:

cd naji-sazan-amin-next && npm run dev

بعد از اتمام کار، برای گرفتن خروجی نهایی npm run build را اجرا کن.

نکته‌های کلیدی این نسخه

📄 چهار صفحه کامل

خانه، درباره ما، پروژه‌ها و تماس با ما — همه فارسی و راست‌چین با فونت وزیرمتن.

🔒 هدرهای امنیتی

سرور داکری همان CSP و سیاست‌های کش و امنیت نسخه پروداکشن را اعمال می‌کند.

🧪 تست‌های خودکار

تست‌های E2E و دود nginx داخل پروژه آماده‌اند و موقع بیلد اجرا می‌شوند.

🔄 به‌روزرسانی ساده

بعد از هر تغییر فقط npm run build؛ کانتینر داکر خروجی تازه را همان لحظه سرو می‌کند.

💡 یک نکته کاربردی:

اگر احساس کردی تغییرات بعد از بیلد در مرورگر دیده نمی‌شود، یک‌بار Ctrl + F5 بزن تا کش مرورگر خالی شود. هر سوالی داشتی یا هر جاش خواستی تغییری بدیم حتماً بهم خبر بده!
