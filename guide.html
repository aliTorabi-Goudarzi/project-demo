نسخه نهایی وب‌سایت

سلام رفیق جان،

این فایل‌ها خروجی نسخه نهایی وب‌سایته که برات آماده کردم. همه صفحات (خانه، پروژه‌ها، درباره ما، تماس) همراه با انیمیشن تعاملی سه‌بعدی هیرو سکشن، قابلیت سوئیچ تم شب و روز، فیلتر پروژه‌ها و فرم استعلام آنلاین تکمیل شده‌اند.

برای اینکه روی سیستم خودت هم دقیقاً مشابه سیستم من، با بالاترین کیفیت، بدون به هم ریختگی فونت‌ها و با لود آنی انیمیشن ببینی، چند روش ساده برات آماده کردم:

روش‌های اجرای وب‌سایت روی سیستم شما
۱ روش اول: اجرای ۱-کلیکی خودکار (سریع‌ترین و راحت‌ترین گزینه - پیشنهاد اصلی من)
بدون نیاز به نصب چیزی

داخل پوشه اصلی پروژه، یک فایل به اسم Run.bat (یا اجرا.bat) برات گذاشتم:

  1. فقط کافیه روی فایل Run.bat دو بار کلیک (دابل‌کلیک) کنی.
  2. سیستم خودکار یک وب‌سرور سبک لوکال ایجاد کرده و مرورگر پیش‌فرض شما رو باز می‌کنه و سایت رو لود می‌کنه!
  3. هر زمان کارت تموم شد، فقط کافیه پنجره سیاه خط فرمان (CMD) رو ببندی تا سرور خاموش بشه.
۲ روش دوم: با پایتون (Python Server)

اگر اهل توسعه و کدنویسی هستی و روی سیستمت پایتون داری:

  1. وارد پوشه پروژه بشو.
  2. کلیک راست کن و Open in Terminal (یا کلید Shift + راست‌کلیک و Open PowerShell) رو بزن.
  3. این دستور رو بنویس و Enter کن:
python -m http.server 8000

حالا توی مرورگرت برو به: http://localhost:8000

۳ روش سوم: ادیتور VS Code یا باز کردن مستقیم

با افزونه Live Server در VS Code:
پوشه پروژه رو با VS Code باز کن، روی index.html کلیک راست کن و Open with Live Server رو بزن.

روش چهارم (باز کردن مستقیم):
اگر هیچ‌کدوم رو نداشتی، کافیه مستقیم روی index.html دابل کلیک کنی تا باز بشه (ولی ترجیحاً از روش ۱ استفاده کن تا ویدیوها و فونت‌ها بدون محدودیت امنیتی مرورگر لود بشن).

اگر احساس کردی فایلی بعد از تغییرات کش شده، کافیه توی مرورگر یک‌بار Ctrl + F5 بزنی تا تمام استایل‌ها تازه بشن. هر سوالی داشتی یا هر جاش خواستی تغییری بدیم حتماً بهم خبر بده!
